```bash
npm install

```

```bash
npm run build

```

## 記事を書く

1. `src/content/blog/` に `article.md` を作る
2. frontmatterと本文を書く
3. 記事URLは `/posts/my-article/` になる

```md
---
title: 記事タイトル
description: 任意の概要
publishedAt: 2026-08-30
tags:
  - 心理学
draft: true
---

ここから
```

- タグを増やす場合は，先に `src/data/tags.ts` へ日本語名と英数字slugを登録する
- 未登録タグを記事に書くとビルドが失敗するので注意

## 記事画像

- 画像は `src/assets/posts/<記事slug>/` に置く
- たとえば `article.md` から `src/assets/posts/article/photo.jpg` を使う場合は次のように書く

```md
![画像の説明](../../assets/posts/article/photo.jpg)
```

- ローカル画像はAstroの画像処理対象となり，寸法指定や最適化が行われる

## ページ構成（統合計画・第2段階）

| URL | 内容 |
| --- | --- |
| `/` | 短いサイト紹介 |
| `/blogs/` | 記事一覧（旧トップの一覧を移動） |
| `/posts/<slug>/` | 記事本文（既存URLを維持） |
| `/tags/`・`/tags/<slug>/` | タグ一覧・タグ別記事一覧 |
| `/search/` | 記事検索 |
| `/experiments/` | 制作物の入口。当面は「準備中」 |
| `/about/` | トップへ転送（GitHub Pagesでは静的HTMLによる転送） |

- Aboutの紹介文はトップへ移動し、サイト沿革は廃止。
- サイト名からトップへ、Blogs・Tags・Experimentsと検索アイコンから各ページへ移動する。
- 現在のページ・セクションは`aria-current`で示し、文字の太さや大きさなどの見た目は変えない。
- URLは既存の`withBase()`を使い、GitHub Pagesのリポジトリ名付きパスにも対応する。
- コードやコールアウトの背景調整は第5段階で行う。

## 共通表示枠（統合計画・第3段階）

- 共通表示枠は最大幅720px。ヘッダーと本文領域を分け、本文をスクロールしてもナビゲーションを操作できる。
- 本文とフッターを同じパネル内でスクロールする。外枠と縦スクロールバーは表示しない。
- ヘッダー・本文パネルの背景色のみ不透明度88％とし、文字や画像は薄くしない。`--panel-opacity`で共通管理する。
- トップのパネルは短い紹介文に合う高さに抑える。内容が画面より長い場合は内部スクロールできる。
- 本文へのスキップリンク、パネルのキーボードスクロール、見出し・脚注への移動用余白を設ける。
- OSの「動きを減らす」設定では滑らかなスクロールを無効化する。
- パネル背後の池は第4段階で組み込み済み。

## 池とページ遷移（統合計画・第4段階）

- `MosaicPond.astro`は全画面固定のCanvasを配置し、`transition:persist`でサイト内の移動中も保持する。
- `BaseLayout.astro`でAstroの`ClientRouter`を使う。ページ遷移のフェードは使わず、池を連続して表示する。
- `src/scripts/pond.js`は単体版の描画本体と公開APIを引き継ぐ。魚の大きさ・泳ぎ・配色・波紋の係数は変更しない。
- `src/scripts/pond-integration.js`が一度だけ初期化・イベント接続する。現在のDOMから入力の除外対象を判定する。
- 本文パネル・ヘッダー・リンク・入力欄などは給餌とマウス回避から除外し、池の余白だけで反応する。
- 鯉〈赤〉7匹・鯉〈青〉7匹・テトラ45匹をヘッダーから選べる。種類の変更時のみ魚を生成し直す。
- Tokyo Night Lightのライト表示に統一し、テーマ切り替え・設定欄・停止ボタンは表示しない。魚種とテーマの永続保存はしない。
- 再読み込みすると初期の鯉〈赤〉へ戻る。同一サイト内のページ遷移・戻る・進むでは魚種と池の実行状態を維持する。
- 本文のスクロールはページ移動ごとに先頭へ戻し、URLにハッシュがある場合はそのリンク先へ移動する。本文位置の履歴復元は実装しない。
- タブ非表示・OSの「動きを減らす」設定での自動停止を引き継ぐ。
- 検索はページ遷移のたびにフォームへ接続し直し、検索語の更新時にもAstroの履歴情報を保つ。
- 背景を非表示にするボタン・スマートフォン専用の停止や表示方法はまだ実装しない。

## 仮決定した項目

- サイト名: `8`)β`
- 本文幅: 720px
- テーマ: Tokyo Night Lightのライト表示のみ。過去の保存済みテーマは読み込まない
- 魚種選択: ヘッダー右側、検索ボタンの右
- ヘッダーナビゲーション: `Blogs` / `Tags` / `Experiments`。サイト名をトップページへのリンクとする
- 検索: ブラウザ内検索
- アラート: NOTE / TIP / IMPORTANT / WARNING / CAUTION
  - 結構ださい
- カレンダー: なし
- Experiments: 準備中ページを作成済み
